# Color King Android Demo

A simple Android WebView wrapper around the Color King virtual-coin demo.

## Build
GitHub Actions builds a debug APK when files under `Color-King-Android/` change. Open the repository's **Actions** tab, select **Build Color King APK**, and download the `color-king-debug-apk` artifact after the run succeeds.

This is a local single-device demo only. It has no real-money functionality, backend, or secure multi-user admin system.
