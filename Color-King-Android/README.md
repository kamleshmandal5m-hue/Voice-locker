# Color King Android

A simple Android WebView app for virtual-coin color play. All credits are virtual and have no cash value. The app does not accept, verify, or process payments and does not support real-money wagering, deposits, or withdrawals.

## Build
GitHub Actions builds a debug APK when files under `Color-King-Android/` change. Open the repository's **Actions** tab, select **Build Color King APK**, and download the `color-king-debug-apk` artifact after the run succeeds.

This app is intended for virtual play only. It does not provide a real-money wallet, payment verification, or cash-out functionality.
